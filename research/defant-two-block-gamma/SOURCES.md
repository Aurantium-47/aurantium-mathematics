# Sources and context

1. Colin Defant, *Fertilitopes*, Discrete & Computational Geometry 70 (2023), 713–752. [DOI](https://doi.org/10.1007/s00454-023-00488-y), [arXiv:2102.11836](https://arxiv.org/abs/2102.11836). This supplies the surrounding binary-nestohedron and stack-sorting context. The polynomial family studied here is defined explicitly in the README and proof.
2. Colin Defant, *Stack-Sorting Preimages of Permutation Classes*, Séminaire Lotharingien de Combinatoire 82 (2020), B82b. [Journal text](https://www.mat.univie.ac.at/~slc/wpapers/s82defant.pdf). The single-fibre real-rootedness question is separate from the log-concavity work in this directory; the repository contains the corresponding [counterexample package](../defant-single-fibre-counterexamples/SOURCES.md).

The Catalan generating function, formal Lagrange inversion, Vandermonde's rising-factorial identity, and exact polynomial interpolation are classical tools. The probability factorization and recurrence are derived explicitly in this package, so their verification does not depend on an external probabilistic preservation theorem. No historical-priority determination is asserted for these partial results.
