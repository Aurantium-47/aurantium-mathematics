# Three-edge reconstruction using type-private unique-weight neighbors

**Theorem.** Let \(T\) be a proper tree with weighted skeleton \(K\) and weight multiset \(W\). A weight is *unique* if it occurs once and *repeated* otherwise. For a repeated weight \(a\), call a unique-weight vertex *\(a\)-private* if it has exactly one neighbor of weight \(a\). Suppose every repeated-weight vertex of weight \(a\) has at least one \(a\)-private neighbor. If the complete profiles queried below are isolated, the full chromatic symmetric function of \(T\) determines it among trees. In particular, this holds if distinct nonempty submultisets of \(W\) of size at most four have distinct sums. The same unique vertex can be private for multiple weights, and there is no bound on its total number of repeated neighbors.

## Reading the forest layers

Use [Orellana and Tomba, Section 3](https://arxiv.org/html/2611.18940v1#S3): Theorem 3.10 and Remark 3.11 recover \(W\) from the leading star-basis partition, and Corollary 3.13 detects properness. Proposition 3.4 supplies deletion-near-contraction. Along its expansion for a proper tree, any dot-contraction introduces an isolated vertex that persists, so only deletions and leaf-contractions contribute to the 1-free star coefficients. Both operations carry a positive sign. For each internal edge, deletion separates components and leaf-contraction adds their weights. Thus the 1-free coefficients count edge subsets of \(K\) by the multiset of component-weight sums. The recovered weights specify the number of pendant leaves at each skeleton vertex. The trivial trees of order at most two are determined by their order and may be handled separately.

For any specified multiset \(\mathcal B\) of nonsingleton blocks of vertex weights whose combined multiset fits in \(W\), append the singleton complement to form a complete block profile. Its sum profile is the multiset of all block sums, including the singleton weights. It is *isolated* if no different complete block profile with that number of blocks and underlying multiset \(W\) has the same sum profile. An isolated coefficient counts exactly the forests with the specified blocks (and singleton complement). This holds even when two blocks have equal sums or two block profiles overlap in weight values. When a template's combined multiset does not fit in \(W\), its forest count is zero; no isolation query is needed. The stronger short-sum condition suffices because every block in the first three edge layers has at most four vertices, so its sum identifies its weight submultiset.

In particular, an isolated triple profile counts the connected induced subsets with that weight multiset: every such subset induces a tree and thus specifies exactly one forest with the other vertices isolated. For two or three pair blocks, the coefficient instead counts unordered matchings with those unordered edge types.

One-edge extraction needs no arithmetic hypothesis. Dividing an edge profile by the product of formal variables \(p_w\) over \(w\in W\) gives the Laurent monomial \(p_{a+b}/(p_a p_b)\) for edge type \(\{a,b\}\). Its sole positive index exceeds both negative indices, so distinct edge types cannot collide. This gives every unique-to-unique edge and, for each unique vertex, the number and weights of its repeated neighbors. In particular, for each repeated weight it detects that weight's private vertices.

## Reconstructing the edges

1. **Name the repeated vertices.** Fix a repeated weight \(a\). For distinct \(a\)-private vertices \(u,v\), adjacency of \(u,v\) excludes a common neighbor by acyclicity. Otherwise query the triple \(\{w(u),w(v),a\}\). A connected subset must include the unique weight-\(a\) neighbor of each representative. The count is one exactly when those neighbors coincide, and zero otherwise. This partitions the \(a\)-private vertices into classes naming the vertices of weight \(a\). In any competitor with the same invariant the classes are the same, and their number at each weight equals the recovered multiplicity, so every repeated vertex in the competitor is named too.
2. **Recover unique-to-repeated edges.** Choose an \(a\)-private representative \(u\) for a class naming \(i\), of weight \(a\). A unique vertex \(v\) that is \(a\)-private is already assigned in step 1. If the one-edge count says \(v\) has no neighbor of weight \(a\), or if \(uv\) is an edge, then \(vi\) is absent; the latter follows by acyclicity. Otherwise query \(\{w(u),w(v),a\}\). Since \(uv\) is absent, any connected triple must contain the sole weight-\(a\) neighbor \(i\) of \(u\), and it is connected exactly when \(vi\) exists. Other weight categories cannot interfere in this three-vertex query.
3. **Recover repeated-to-repeated edges.** Let \(i,j\) be distinct named repeated vertices of weights \(a,b\), with chosen type-private representatives \(u,v\) respectively. If \(u=v\), \(ij\) is absent by acyclicity. Otherwise the fixed edges \(ui,vj\) are disjoint, and each is the sole edge of its type (unique representative's weight, private into the indicated type). Let \(E\) count all edges of type \(\{a,b\}\), known from one edge. Let \(D_i\) be the two-edge count for pair blocks \(\{w(u),a\},\{a,b\}\), so \(d_i=E-D_i\) counts the edges of type \(\{a,b\}\) incident with \(i\): a repeated-to-repeated edge cannot touch the uniquely weighted \(u\). Define \(D_j,d_j\) analogously using \(v\). Let \(M\) be the three-edge count for pair blocks \(\{w(u),a\},\{a,b\},\{b,w(v)\}\). The three types are distinct because the two unique weights differ and only the middle type uses two repeated weights. Each counted matching therefore corresponds to one middle edge disjoint from both fixed edges, with no ordering factors. By inclusion–exclusion,
   \[
   \mathbf{1}_{ij\in E(K)}=M-E+d_i+d_j .
   \]
   The intersection of the middle edges incident with \(i\) and the middle edges incident with \(j\) consists exactly of the edge \(ij\) if present. This is unchanged when \(a=b\); an edge \(ij\) then contributes once to each degree and once to the intersection.

Apply the same decoding to a tree with equal chromatic symmetric function. Properness, \(W\), and the forest coefficients agree by the cited reduction. Choose representatives deterministically from the classes, for example by minimum weight, so the queried profiles agree. The resulting skeletons and their expansions are isomorphic. This is a full-\(X\) theorem, not a claim about the specialized derivative.

**Alternative query for globally private representatives.** When each repeated vertex can be represented by a unique vertex with just one repeated neighbor *in total*, use only such vertices for the grouping in step 1. In step 2, check each remaining unique vertex unless its incidence is already known (regardless of whether it is private within the weight class). For step 3, if \(u,v\) are adjacent, \(ij\) is absent by a four-cycle. Otherwise connectivity of the induced subset of weights \(\{w(u),w(v),a,b\}\) forces the fixed neighbors \(i,j\), and is equivalent to \(ij\) being present. Thus the earlier theorem needs only its queried connected triples and quadruples to have isolated profiles. This alternative does not require isolation for any matching templates.

The two-edge counting method has a prior analogue: [Aliste-Prieto, de Mier, Orellana and Zamora](https://arxiv.org/html/2202.11787), Lemma 7.4(b) in the linked arXiv numbering, reads independent pairs from the marked polynomial. Their proof of Theorem 7.13 also analyzes independent versus adjacent pairs in the unmarked coefficients for strictly weighted 2-stars. Corollary 5.9 and Theorem 5.10 in that source give the unmarked polynomial from the 1-free star coefficients. Here the extra ingredient is the three-edge matching count with two specified type-private edges. Priority for the resulting criterion is not established.

## Exact fixtures

The 138-vertex fixture ([`checks/private_arithmetic.py`](checks/private_arithmetic.py)) also needs the weaker graph condition. Take weights `(2,2,3,3,4,14,15,23,24,48)` on vertices 0–9 and common edges `04,15,26,37,48,09,19`. Add `02,13` in one tree and `03,12` in the other. Vertices 4–7 are private and name all four repeated vertices. The unique-weight vertex 9 has two repeated neighbors, so the earlier requirement that each unique vertex have at most one fails. Also `4=2+2`, so short-sum separation fails. Exact enumeration of all 750 two-edge and 5,880 three-edge set partitions verifies isolation for a superset of the needed queries: 17 triple profiles and six quadruple profiles. Forest layers 0–2 agree; the third-layer profile `(2,3,14,23,24,24,48)` has counts 1 and 0. The triple queries involving vertex 9 recover its incidences `(1,1,0,0)` to the four named repeated vertices in both trees. No minimum-size or priority claim is made.

The 258-vertex fixture ([`checks/type_private.py`](checks/type_private.py)) meets the type-private graph hypothesis, but has no globally private unique vertex. Use weights `(2,2,2,2,5,5,5,5,19,33,61,117)` on vertices 0–11. For each \(i=0,1,2,3\), join \(8+i\) to \(i\) and \(4+i\). Both trees also have the edge \(8\text{--}9\). Add \(0\text{--}6,1\text{--}7\) in the first and \(0\text{--}7,1\text{--}6\) in the second. All 103 distinct weight submultisets of size 1–4 have distinct sums. Again layers 0–2 agree. For vertices 0 and 6 with representatives 8 and 10, the ordered tuple \((E,d_i,d_j,M)\) is \((2,1,1,1)\) in the first tree and \((2,1,1,0)\) in the second. The third-layer sum profile is `(2,2,5,5,7,21,33,66,117)`. The checker also tests same-weight pairs with feasible and infeasible matching templates.
