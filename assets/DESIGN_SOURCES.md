# 看板版式参考

研究概览采用白色面板与浅雾绿配色，排版参考[shadcn/ui官方Dashboard 01](https://ui.shadcn.com/view/new-york-v4/dashboard-01)及其[SectionCards组件](https://ui.shadcn.com/r/styles/new-york-v4/dashboard-01.json)：紧凑的指标卡片、轻边框、小幅圆角，以及指标与明细分栏的结构。

shadcn/ui的软件许可为MIT，原许可文本保留于[shadcn-layout-LICENSE.txt](shadcn-layout-LICENSE.txt)。本目录的研究图采用静态图片适配GitHub README，并分别提供桌面与手机版式。数值来自[data/frontpage_statistics.json](../data/frontpage_statistics.json)及[data/result_counts.json](../data/result_counts.json)。

数学论文、证明、形式化源码与第三方文献的权利和许可，继续按各项目的原有说明执行。
