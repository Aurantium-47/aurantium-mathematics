# 研究概览版式

当前版本采用纯白背景、黑灰文字与单一蓝色点缀。标签置于数值上方，以统一字级、列起点、基线和间距组织六项数据；不使用渐变、彩色分列、圆角卡片、阴影或辅助小字。

排版参考[Swiss Design Skill](https://github.com/zeke/swiss-design-skill)（[MIT许可](https://github.com/zeke/swiss-design-skill/blob/main/LICENSE)）的网格、字体层次与单一强调色，以及[Bauhaus / Swiss Design Skill](https://github.com/capsrock/bauhaus-design-skill)（[MIT许可](https://github.com/capsrock/bauhaus-design-skill/blob/main/LICENSE)）浅色数据示例的数字排版。图形由本项目独立绘制，没有复制示例图片或第三方组件代码。

数字和英文采用[IBM Plex Sans](https://github.com/IBM/plex)，遵循[SIL Open Font License 1.1](https://github.com/IBM/plex/blob/master/packages/plex-sans/LICENSE.txt)；中文采用Noto Sans SC。公开图像不包含字体文件。

研究概览采用静态图片适配GitHub README，分别提供中英文桌面与手机版式。数值来自[data/frontpage_statistics.json](../data/frontpage_statistics.json)及[data/result_counts.json](../data/result_counts.json)。上一版参考的shadcn/ui许可文本保留于[shadcn-layout-LICENSE.txt](shadcn-layout-LICENSE.txt)。

数学论文、证明、形式化源码与第三方文献的权利和许可，继续按各项目的原有说明执行。
