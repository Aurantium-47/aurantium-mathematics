# Aurantium · Mathematics

**Proofs, counterexamples, and extensions.**

[中文](README.md) · [English](README.en.md) · [Detailed report in Chinese](REPORT.zh.md)

A collection of 24 public research projects in combinatorics, graph theory, polynomial theory, and asymptotic analysis. Eight projects include Lean formalization, eight develop an additional group of results, and seven contain a counterexample or negative certificate.

Highlights include the remaining cases of Howroyd's 27-set classification; degree-multiplicity extremizers for chemical graphs for every n ≥ 7; Lecture Hall polynomiality and signed Dyck identities; a sharp 23-colour result for K6 clique chains supported by an exact certificate; and a 237-step fence-rowmotion orbit refuting the proposed statistic.
